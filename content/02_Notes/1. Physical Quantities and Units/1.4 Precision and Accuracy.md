-*+# Precision
- The precision of a measurement is how close the measured values are to **each other**.
- If a measurement is repeated several times, it can be described as precise if the values are very close or the same as each other.
- Precision is affected by random errors.
# Accuracy 
- The accuracy of a measurement is how close the measured value is to the **true value.**
- Accuracy is affected by systematic errors.
