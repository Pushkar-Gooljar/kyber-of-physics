# Point 1

>[!danger] SUPER IMPORTANT
>For graphs only scales that are in the following format are considered not awkward:
> $$\Large1,2,5 \times 10^x, \quad x \space\text{is an integer}$$
> Examples of acceptable scales:
> - $0.1$
> - $0.02$
> - $500$
> 
> **ANYTHING ELSE IS CONSIDERED AWKWARD**: -1 or more marks

# Point 2
>[!danger] SUPER IMPORTANT
>- Number of significant figures depend on rows.
>- Each row is independent of each other.
>- SF should be same as least SF
>- It is unnecessary and often incorrect to force SF in a column to match
>
>Example:
>If there is **A/cm**, **B/cm**, and **A/B /cm** where **A** and **B** are measured and **A/B** Calculated:
>- If for a given row, **A** is 2 SF and **B** 3 SF, **A/B** should be 2 SF as that is the least SF
